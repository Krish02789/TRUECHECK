# TRUECHECK
Built a full-stack web application "TrueCheck", a background verification tool that enables candidates to submit details (Aadhaar, PAN, education) and companies to view verification status.

## Features
- **Admin Portal**: Manage candidates, view verification status, send OTP for Aadhaar verification
- **Candidate Portal**: Submit personal details, track verification status
- **Aadhaar Verification**: OTP-based verification system with mock fallback
- **Email Verification**: Email OTP system for additional verification
- **Modern UI**: Beautiful, responsive design with glass-morphism effects

## Tech Stack
- **Frontend**: React + Vite
- **Backend**: Node.js + Express
- **Styling**: Custom CSS with modern design
- **Deployment**: Vercel

## Getting Started
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` for development
4. Run `npm run build` for production build
