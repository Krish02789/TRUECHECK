# TrueCheck ✅

TrueCheck is a full-stack background verification platform that helps manage candidate verification workflows securely and efficiently.

## 🚀 Features

- User authentication
- JWT-based secure login
- Role-Based Access Control (RBAC)
- Candidate verification management
- Admin dashboard
- Responsive interface

## 🛠 Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- JWT Authentication
